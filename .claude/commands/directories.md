## Step 3: Prioritize

Score each directory by:
- **Domain Rating** — higher DR = more valuable backlink
- **Link type** — dofollow > nofollow (but nofollow from DR 90+ still valuable)
- **Relevance** — does the audience match?
- **Traffic** — does the directory actually send traffic?
- **Effort** — free submission vs requires review/payment
- **Cost** — free is obviously preferred for initial rounds

Present a prioritized table to the user, grouped into:
1. **Must-do (free, high DR, dofollow)**: SourceForge, G2, Capterra, Wellfound, F6S, StackShare
2. **High value (free, DR 70+)**: SaaSHub, AlternativeTo, BetaList, Alternative.me, SoftwareWorld, etc.
3. **AI-specific** (if applicable): TAAFT, Toolify, Futurepedia, etc.
4. **Dev-specific** (if applicable): GitHub Awesome Lists, free-for-dev, DevHunt, etc.
5. **Nice-to-have**: remaining directories sorted by DR

## Step 4: Map Submission Assets to Directories

| Field needed | Source from Submission Assets |

Only flag where a directory needs something **not covered** by the standard assets (e.g., a specific badge, a unique field like StackShare's "tech stack" or StartuPage's revenue verification).

## Backlink Strategy Notes

- Target 20-40% nofollow for a natural backlink profile
- Even nofollow from DR 90+ (Crunchbase, Trustpilot) carry indirect SEO value
- Expected result: DR 0 → DR 25-35 within 2-3 months with 40-60+ quality submissions
- Prioritize dofollow links from DR 80+ sites first (SourceForge, G2, Capterra, Wellfound, F6S, StackShare)
- GitHub links (DR 97) are nofollow but provide massive discovery value
